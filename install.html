Kick

New Project Starter Kit for Claude Code

A conversational kickoff system that scaffolds new projects through a guided /kickoff flow. You answer questions, Claude produces the docs.

Prerequisites

  • Claude Code installed
  • Git

Install

  1. Clone the repo: 
    git clone https://github.com/patchythegildedmoth/kick.git ~/Code/kick
  2. Run the setup script: 
    cd ~/Code/kick
./setup.sh
    This symlinks the /kickoff slash command and skill into ~/.claude/.

Usage

  1. Create an empty folder for your new project.
  2. Open Claude Code in that folder.
  3. Type /kickoff and follow the conversation.

Claude walks you through 7 gated phases — problem & scope, prior-art research, architecture, workflow setup, design, build plan, and pre-flight — producing a full set of project docs along the way.

The playbook repo stays where you cloned it. Nothing gets copied into your project folders — /kickoff reads from the playbook and generates docs directly in your project directory.

What you get

  • PROJECT_BRIEF.md — problem, users, scope, success criteria
  • RESEARCH.md — prior art, open-source candidates, competitors
  • ARCHITECTURE.md — stack decisions with tradeoffs
  • CLAUDE.md — agent config, skills, MCPs
  • DESIGN.md — visual direction (when applicable)
  • BUILD_PLAN.md — phased roadmap with done criteria
